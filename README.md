# CineMesh 🎬⚡
> **High-Fidelity 1080p Screen & 6GB Movie P2P Streaming Engine** with Lossless Opus Stereo Audio.

Built with:
- **Frontend**: React + Vite + Tailwind CSS + Lucide Icons (Deployable on Vercel)
- **Signaling Server**: Node.js + Express + Socket.IO (Deployable on Render / Koyeb)
- **Engine**: WebRTC (`RTCPeerConnection`), SDP Munger (192-256kbps Opus Stereo), HTML5 Media Capture API
- **Cost**: 100% Free (₹0 budget, no cloud egress fees, direct P2P mesh)
